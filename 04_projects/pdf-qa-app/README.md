# 📚 AI PDF Knowledge Assistant

An AI-powered Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and ask natural language questions about their content.

The system combines semantic search, vector databases, transformer embeddings, and LLM-based answer generation to provide grounded and context-aware responses.

---

## 🚀 Features

* PDF Upload & Text Extraction
* Semantic Search using Sentence Transformers
* FAISS Vector Database for fast retrieval
* Retrieval-Augmented Generation (RAG)
* AI-powered answer generation
* Query rewriting & hybrid retrieval
* Streamlit-based interactive UI
* Local and cloud LLM support

---

## 🧠 Tech Stack

* Python
* Streamlit
* Sentence Transformers
* FAISS
* OpenRouter API
* TinyLlama / GPT Models
* PyMuPDF
* Scikit-learn

---

## ⚡ System Architecture

PDF → Chunking → Embeddings → FAISS Retrieval → Context Grounding → LLM Generation → AI Answer
